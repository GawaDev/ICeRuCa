# 困ったときは

## 実際には使える場所が「利用できません」になる

選択したエリア、交通事業者、利用目的を確認してください。地域カードは同じ地域でも対象路線が限られる場合があります。未収録の組み合わせは、利用不可と推測せず「公式情報で確認できません」と表示します。

## 駅間検索で「条件があります」になる

駅間検索だけでは実際の列車、経由路線、営業キロを確定できないためです。特に異なるIC利用エリアをまたぐ経路は、自動改札を利用できない場合があります。

## 地図が表示されない

ページを再読み込みしてください。背景地図は外部へ接続せず、アプリに収録した駅と路線だけを表示します。

## 古い情報に見える

各結果の「根拠」に確認日を表示しています。公式ページの内容が変わっている場合は、公式情報を優先してください。
