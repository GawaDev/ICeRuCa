# カードから確認する

1. 画面上部で「カード」を選びます。
2. カードと種類を選びます。通常カード、モバイル、小児用、地域連携カードを収録しています。
3. 「地図」で交通利用と電子マネーの対応状況を確認します。
4. 「全エリア」で会社ごとに分かれた全ICエリアの結果を確認します。
5. 「サービス」でポイント、定期券、予約、チャージを確認します。
6. 「駅例外」で乗車不可、一部対応、条件付きの駅を確認します。

結果は次の4種類です。

- **利用できます**: 選択した組み合わせを公式情報で確認済みです。
- **利用できません**: 対象外であることを公式情報で確認できます。
- **条件があります**: 路線、予約、登録、媒体など追加条件があります。
- **公式情報で確認できません**: 収録情報だけでは断定できません。

地図は色分けした実軌道を表示します。駅はズーム8以上で表示し、選択すると駅名と路線を確認できます。駅例外データが未生成の場合は生成待ちと表示します。

交通利用と電子マネーは別々に表示します。PiTaPaなど、交通利用が可能でも全国相互利用の電子マネー対象外となるカードがあります。
