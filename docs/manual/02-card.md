# カードから確認する

1. 「確認方法」で「カード」を選びます。
2. カードと媒体を選びます。
3. 「交通利用」「電子マネー」など、確認したい利用目的を選びます。
4. 利用エリアを選びます。
5. 「確認結果」で結果、条件、公式の根拠を確認します。

結果は次の4種類です。

- **利用できます**: 選択した組み合わせを公式情報で確認済みです。
- **利用できません**: 対象外であることを公式情報で確認できます。
- **条件があります**: 路線、予約、登録、媒体など追加条件があります。
- **公式情報で確認できません**: 収録情報だけでは断定できません。

地図の駅を選ぶと右側に駅名、路線、境界駅の注意を表示します。
