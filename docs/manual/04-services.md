# 定期券・新幹線・ポイント

カードの交通利用可否から、次のサービスを推測することはできません。「サービス」で個別に確認してください。

## 定期券

カード発行事業者、定期区間、連絡会社、媒体により購入できる範囲が異なります。エリアをまたぐIC定期券は、指定された定期区間内だけ利用できる場合があります。

## 新幹線

- スマートEXは予約と乗車用ICカードの指定が必要です。代金はIC残高から引かれません。
- 新幹線eチケットは予約した座席とICカードの紐付けが必要です。
- タッチでGo!新幹線は初回登録後、対象区間の自由席をチャージ残高で利用します。

## ポイント

相互利用先でカードを使えても、相互利用先の独自ポイントが付くとは限りません。会員登録、利用登録、対象路線などをサービス提供者の公式情報で確認してください。
