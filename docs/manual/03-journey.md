# 駅間と乗換を確認する

## 駅間検索

「駅間検索」を選び、カード、乗車駅、降車駅を選びます。乗車駅、降車駅、IC利用エリア、利用経路を別々に確認します。

駅名が同じでも、事業者やエリアが異なる候補は別項目として表示します。熱海や米原などの境界駅では、選んだ事業者側を確認してください。

経路、列車、営業キロが確定しない場合、両駅が対応していても「利用できます」とは表示しません。実際に利用する経路を交通事業者の案内で確認してください。

## 乗換改札

「乗換改札」を選び、駅を選びます。表示された順に操作します。磁気券、企画券、定期券を併用する場合は操作が異なるため、現地の改札表示と係員案内を優先してください。
