# 駅間と乗換を確認する

## 駅間検索

「駅間検索」を選び、出発駅と到着駅を候補から選んで「確認する」を押します。公開されている全駅データから検索します。

結果では「発駅IC」「着駅IC」「エリア」「営業キロ」「ラッチ接続」を独立して表示します。あわせて総合結果、概算距離、経由路線、確認上の注記を表示します。マイナスのアイコンは利用不可ではなく、その条件を評価できないか対象外であることを示します。

駅名が同じでも、事業者やエリアが異なる候補は別項目として表示します。熱海や米原などの境界駅では、選んだ事業者側を確認してください。

経路、列車、営業キロが確定しない場合、両駅が対応していても「利用できます」とは表示しません。実際に利用する経路を交通事業者の案内で確認してください。

駅データが0件の場合は生成待ちと表示します。この状態では検索できません。

## 乗換改札

「乗換改札」を選び、駅名または会社名で検索します。利用する組み合わせを開き、番号順に操作します。磁気券、企画券、定期券を併用する場合は操作が異なるため、現地の改札表示と係員案内を優先してください。
