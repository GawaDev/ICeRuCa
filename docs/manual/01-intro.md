# はじめに

ICeRuCaは、交通系ICカードをどこで、どの目的に利用できるかを公式情報から確認するWebアプリです。

## 確認できること

- カードと利用エリアの組み合わせ
- 交通事業者が案内する利用エリア
- 乗車駅と降車駅のエリア条件
- 乗換改札の操作
- 定期券、電子マネー、新幹線、ポイントの個別条件

「全国相互利用」は全国すべての交通機関で使えるという意味ではありません。また、交通利用、電子マネー、定期券、ポイント、新幹線はそれぞれ別の制度です。

画面上部の「カード」「会社」「駅間検索」「乗換改札」「サービス」から確認方法を直接選べます。スマートフォンでも5つの確認方法を上部から直接選べます。各画面の内容は画面内でスクロールします。

地図はOpenStreetMapを背景に、2025年度国土数値情報から生成した18,113の鉄道路線要素を重ねます。駅間検索には同データの全10,234駅を収録しています。駅は地図をズーム8以上にすると表示します。
