# データと更新

利用可否データには公式URL、発行者、確認日、有効期間を保持します。制度変更を検出しても自動で利用可否を変更せず、対象範囲と発効日を確認して更新します。

鉄道形状は国土交通省「国土数値情報（鉄道データ）N02-2025」を加工して利用できます。N02にはIC利用可否、運賃、改札、定期券条件が含まれないため、利用可否の根拠には使用しません。

地図用生成処理はN02 GeoJSONから必要な属性だけを抽出します。元データを配置していない開発環境では、収録済みの最小データを維持します。

地域カード、バス路線、期間限定キャンペーンは全国一括の台帳がないため、発行者と運行事業者の公式案内を個別に確認します。
