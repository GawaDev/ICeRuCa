# セキュリティとプライバシー

検索条件と選択内容はブラウザ内で処理します。サーバーへ検索内容を送信せず、Cookie、利用者アカウント、アクセス解析を使用しません。

Web Serviceは静的ファイルとヘルスチェックだけを提供します。Content Security Policy、HSTS、MIMEスニッフィング防止、フレーム埋め込み制限を設定します。

外部サイトへの通信は、利用者が「根拠」の公式リンクを選んだときだけ発生します。地図表示は外部タイルサービスを利用しません。

脆弱性の連絡方法は公開サイトの `/.well-known/security.txt` と `SECURITY.md` に記載します。
